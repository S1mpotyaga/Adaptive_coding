# Адаптивное кодирование изображений

## Цель

1. Реализовать алгоритм адаптивного кодирования изображения

2. Реализовать несколько модификаций этого алгоритма

3. Сравнить реализованный алгоритм с существующими алгоритмами кодирования изображений jpg и png

## Описание алгоритма

Есть некоторое изображение `image`, которое представляется в виде матрице `N x M`. Каждый пиксель задается 3 значениями RGB, поэтому давайте разобьем каждую строчку `image` на 3 по каждому из значению RGB. Тогда по сути каждая строка изображения - дискретный сигнал, который можно закодировать. Как будем его кодировать? Пусть $t_k$ - значение сигнала в момент времени k. Тогда давайте смотреть на знак значения $t_{k + 1} - t_k$ и кодировать этот знак в виде одного бита, где 0 - изменение сигнала на `-const`, 1 - изменение сигнала на `+const`. Есть некоторые нюансы в реализации алгоритма, которые будут описаны в файлах `README.md`, соответствующих реализаций на языках `C++` и `Python`.

## Ход работы

1. Одномерная реализация алгоритма без адаптивного зуминга

2. Одномерная реализация алгоритма с адаптивным зумингом

3. Двумерная реализация алгоритма с адаптивным зумингом

4. Реализация нескольких модификаций алгоритма

5. Сравнение реализованного алгоритма с алгоритмами `jpg` и `png`
