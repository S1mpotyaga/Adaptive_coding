# Реализация на языке C++

## Ход работы

1. Одномерная реализация алгоритма сжатия с фиксированным шагом (шаг занимает 1Б);

2. Одномерная реализация алгоритма с фактором роста (шаг занимает 1Б);

3. Одномерная реализация алгоритма с адаптивным зумингом (шаг занимает 1Б);

4. Двумерные реализации модификаций алгоритма адаптивного сжатия (шаг занимает 1Б);

5. Двумерные реализации модификаций алгоритма адаптивного сжатия (шаг занимает 1 бит);

6. Подсчет метрик: время, потраченное на кодирование и декодирование, сигнала (изображения), и затраченной памяти;

7. Сравнение реализованного алгоритма с алгоритмами `jpg` и `png`;


## Подведение результатов

> На данном этапе реализованы первые 4 пункта.
> Графики и изображения можно посмотреть в папке /cpp/images.

Для одномерного сигнала были построены графики сравнения исходного и закодированного сигналов. Эти графики можно посмотреть в папке  `cpp/images/one-demensial`. 

Для двумерного сигнала так же были приведены результаты кодирования. Графики сравнения исходного изображения с декодированным можно посмотреть в папке `cpp/images/two-demensial`.

## Следующие действия

Сначала будет реализовано сохранения знака в одном бите, а не в одном байте. А затем будет реализован подсчет среднеквадратичной ошибки, потраченного времени и памяти, и тогда можно будет посмотреть, какой из способов лучше справляется с задачей кодирования.
